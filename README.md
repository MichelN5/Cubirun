# Cubirun

A simple 3D obstacle-running game built with **Unity** and **C#**.

The player controls a blue cube moving across a platform and must avoid the obstacles placed along the course. The score increases as the run continues, making the goal simple: stay on the platform, avoid collisions, and reach the highest score possible.

## Gameplay

- Control a cube moving through a 3D obstacle course
